# 30 TRAPS

「30回釣られたあと、自分が釣られていた時間を見せつけられるサイト」。
**Rickroll はオチではなく1層目**という企画。元ネタは Vault の `Clippings/技術で釣るサイト案.md`。

素の HTML / CSS / JS 1セット。ビルド不要。`public/games/okoraretarakesu/index.html` を開けば動く。

---

## 遊びの流れ

| 段階 | 何が起きるか |
|---|---|
| ① 釣り画像 | 2008年ごろの無料ゲームサイト風。画像を押した**瞬間に、画面上部のタイマーが動き出す** |
| ② ブロック崩し | **ブロックの下に絵が敷いてある。** 崩すほど見えてくる |
| ③ 報酬 | 全部崩すと、絵の続きではなく**「お待たせしました」**が出る |
| ④ TRAP 01〜30 | 背景に全身の絵。**ウィンドウの山がボードを覆っているので顔と足しか見えない**。どかすと次の釣り動画 |
| ⑤ リザルト | 30枚目をどかすと**その場でタイマーが止まり、ボードに時間が出る**。画面は切り替わらない |

### タイマー（`#clock`）

**初見でもRTAでも、押した瞬間から画面上部の真ん中に出続ける**（本人の指示・2026-09-02
「サイトそのものにタイマーが出てきて、最初の動画のとこクリックしたら始まる」「初見の計測時もそれで揃えとこうか」）。

- 位置は `position: fixed` の上端中央。**ページの上でもTRAPデスクの上でも同じ場所**に出る
- 初見／再走は緑で「経過時間」、RTAモードは金色で「RTA」
- 止まると赤くなり、**そのときだけミリ秒まで**出す
- 裏のタブでは `requestAnimationFrame` が止まるので表示は凍るが、
  計測は `performance.now()` なので**時間は進み続ける**（戻ると飛ぶ。仕様）

計測は①から④の30枚目まで。**ブロック崩しで死んでもタイマーは止まらない。**

### 絵の使い方（本人の指示・2026-09-02）

> 最初は顔だけ映しとくんだ / ボードにかかった時間を出すんだ /
> 顔と足だけ見えるように設置しといて、最後のウィンドウ動かしたらタイマーすっとっぷ

**ボードの内側の座標がこの作品の背骨。** 元画像(1086×1448)で `left:263 top:678 589×317` ＝
**左24.22% / 上46.82% / 幅54.24% / 高さ21.89%**。
この割合を、TRAPデスク・リザルト・共有カードの3か所で共用している（`BOARD`）。

| 場面 | 絵の使い方 |
|---|---|
| ① 釣り画像 | **顔だけ**。元絵から `left:260 top:100 700×394` を切って 16:9 に。制服が入らない高さ |
| ② ブロック崩し | ブロックの下に顔の絵。**壊した穴からだけ見える**（`FIELD` にクリップして描く） |
| ④ TRAPデスク | **全身を背景に敷き、ボードの内側＝動画ウィンドウの本体になる倍率で置く。**
  だからウィンドウの山がちょうどボードを隠し、顔と足だけが見える |
| ⑤ リザルト | 30枚目が退くと、ずっとそこにあったボードが見える。SVGで時間を重ねる |

- デスクの倍率は**画面の高さ基準**。横ははみ出してよい（左右は余白なので切れて困らない）。
  ウィンドウが 280px を割るときだけ、頭と足が切れても絵を大きくする
- ウィンドウ本体は 16:9、ボードは 1.86:1。**必ずウィンドウのほうが縦に大きい**ので隙間から漏れない
- 共有カードは Canvas で同じ割合を使って描く。**枠線は絵より後に引く**（先に引くと絵に隠れる）
- 元PNG 1,701KB → webp 52KB＋98KB

## 広告枠（全10枠・全部が売り物）

外周にある広告枠は**すべて実際に売る枠**。**偽広告は置かない**（本人の指示・2026-09-02
「これだったら偽広告の部分、全部広告枠にしてもなんの問題もない」）。空いている枠は
「この枠、空いてます／500円」と静かに出る。

| 位置 | 枠数 | 大小 | 価格 |
|---|---|---|---|
| 画面いちばん上・横長 | 2 | 大 | 1,000円 |
| ゲームの下・横長 | 1 | 大 | 1,000円 |
| 左の柱・縦長 | 3 | 小 | 500円 |
| 右の柱・縦長 | 3 | 小 | 500円 |
| 右下の小窓 | 1 | 小 | 500円 |

**売るときは `sponsors.js` の該当位置を書き換えるだけ。**

```js
top: [{ name: '○○', text: '一行説明', url: 'https://…' }, null],
```

### 決めてあること

- **本物と偽物は見た目を変えている。** 本物＝白地＋黒の「広告」ラベル、偽物＝黄色や赤＋「PR」。
  同じ見た目にすると、出してくれた人の広告がネタの一部だと思われて枠の価値が消える
- **本物だけがリンクする。** 偽広告はどこにも飛ばない
- 外部リンクには `rel="nofollow sponsored noopener"` が自動で付く
- **30枚目のあと、偽広告は全部消える。** 売れている枠だけ、結果の下に
  「この記録は ○○ の提供でお送りしました。」として一行残る
- 価格・掲載期間・申し込み先は `sponsors.js` の `SPONSOR` にまとまっている。
  ページ下の案内文と空き枠数は、そこから自動で組み立てられる

### 期限が来たら勝手に外れる

**手で外す作業を残さないための仕掛け**（本人の指示・2026-09-02「勝手に3日で外れるようにしよう」）。

- 枠には `until: 'YYYY-MM-DD'` が**必須**。この日を過ぎると表示されず、自動で「空いてます」に戻る
- `until` を書き忘れた枠も出ない。**貼りっぱなしが起きない側に倒してある**
- `from` を書けば「その日から出す」もできる（先に入れておける）
- 判定は閲覧者のブラウザの日付（日本時間）。厳密な課金の証拠には使えないが、この用途には足りる

### 掲載条件

`sponsors.js` の `SPONSOR_RULES` が正本。**最初は厳しめ**（本人の指示・2026-09-02）。
NGは12項目（アダルト／ギャンブル／投資・副業・情報商材／医療健康の効果／占い宗教政治／
無許可販売／作風模倣／誹謗中傷／マルチ／短縮URL／広告表示を隠す要望／この作品の演出に紛れる表現）。
**迷ったら断る。** 枠は10しかないので、埋めることより並びの質を優先する。

## ブロック崩し

**マルチボール付き。** 白い点のついたブロックを壊すと、その場からボールがもう1個出る（最大6個）。
**ボールが全部落ちたときだけ残機が減る。**

| | 段×列 | ブロック | 初速 | 上限速度 | パドル | 増殖ブロック |
|---|---|---|---|---|---|---|
| かんたん | 4×8 | 32 | 2.9 | 4.4 | 96 | 24% |
| ふつう | 6×10 | 60 | 3.4 | 5.4 | 78 | 18% |

ブロックは `FIELD`（480×222・y38から）を隙間2pxで埋める。**先に隙間から絵が見えないように gap は詰めてある。**

速度には**上限がある**（`max`）。上限を入れないと終盤に手がつけられなくなる。
値は全部 `game.js` の `DIFFS` にある。**長さを変えたいときは `rows` を、難しさを変えたいときは `speed` と `max` を触る。**

実測（人間くらいの精度で自動プレイ・かんたん）：**約61秒でクリア。**
最下段は増殖ブロックにしない（いきなり増えると事故になる）。

**ど真ん中で受け続けると真上に往復して詰む**（空いた列を上下するだけになる）。
パドルの跳ね返しで横成分を必ず 9% 残して防いでいる。自動テストで実際に踏んだ。

## 実装で効いているところ

- **YouTubeの実プレイヤーは常に1個だけ。** 30個同時読み込みはしない。
  `#playerHost` を固定で持ち、アクティブなウィンドウの位置へ `transform` で重ねる。
  DOMの付け替えをしないので **iframeが再読み込みされない**
- 残り29枚は `i.ytimg.com` のサムネ1枚。どかした瞬間に初めて読み込む
- ドラッグはタイトルバーだけ（`touch-action:none`）。動画本体を掴ませないので YouTube の操作と喧嘩しない
- ウィンドウの `×` は**閉じない**。閉じられたら企画が成立しない
- **1本目の自動再生**：ブラウザが音つき再生を許すのは「押した操作の続き」だけなので、
  YouTube API が来ていれば**待たずにその場でプレイヤーを作る**。
  以前は 120ms ごとのポーリングを挟んでいて、1本目が鳴らないことがあった
- 弾かれたら「クリックで再生」を重ねる。**ウィンドウを掴んだ瞬間にも鳴らしにいく**（`nudgePlay`）
- YouTube API が来なくても、サムネのまま最後まで進める

## 開発用のクエリ

| 付ける | 効果 |
|---|---|
| `?skip=1` | ブロック崩しを崩し終わった状態にする（TRAP側の確認用） |
| `?dev=1` | `window.__bk`（ブロック崩しの状態）と `window.__bkTick(n)`（手動で1フレーム進める）を生やす |

どちらもクエリが無ければ何も生えない。
