# SCRATCH ARCADE

ジョグをまわす音ゲー。企画書『DJコントローラー・ターンテーブリズム音ゲー』の **§15 MVP** の範囲。

- `index.html` — 画面とCSS
- `game.js` — **調整表 `T`**・音・MIDI・入力・判定・描画
- `ui.js` — 画面遷移・チュートリアル・キーボード

## 動かす

```bash
python -m http.server 8123 --bind 127.0.0.1
```

→ Chrome / Edge で `http://127.0.0.1:8123/`。
Web MIDI は **secure context** でしか動かないので、`localhost` か `https://` から開く。

## 操作

| | |
|---|---|
| **DJコントローラー** | 左右のジョグ＋クロスフェーダー。初回は MIDI 画面で覚えさせる |
| **キーボード** | `F` 左ジョグ前 / `D` 左ジョグ後 / `J` 右ジョグ前 / `K` 右ジョグ後 / `SPACE` フェーダーを切る / `ESC` 中断 |

CHIRP は「前に押して、音が出ている途中で切る」。キーボードなら `F` → すぐ `SPACE`。

## 作風

**カワイイ・フューチャーベース／フューチャーコアの畑に寄せてある。**

- ジャケットの面（タイトル・モード選択・リザルト）は**パステルのグラデーション＋網点＋粒子**。
  文字は Anton の詰めた大見出しと Zen Maru Gothic の丸ゴシック。ボタンは**厚いオフセット影のステッカー**。
- 演奏中は**深い紫のフロア**に切り替わる。ノーツはフラット色＋白フチ＋硬い影のステッカーで、
  1枚ずつ角度がずれている。技名は**色ズレ（ピンク／シアン）**、判定文字はハードシャドウ。
- **キックに合わせて画面全体がわずかに縮む**（サイドチェインの見た目版）。
  背景の色はセクションで変わる。ドロップの瞬間だけ白が抜ける。
- 下端に流れっぱなしのティッカー、右端に縦組みの帯、左上にトラック表記。

避けたもの：等幅フォントを字間で伸ばした小見出し、角丸カードの整列グリッド、
紺地にシアンの発光。要するに**既定のダッシュボードの顔**。

## 音

音源ファイルを1つも置いていない。全部その場で合成する。

- **曲『まだ、まわしてる』**：150 BPM のハーフタイム。**フューチャーベース**。
  スーパーソウのコードスタブ（王道進行 IV-V-iii-vi）／サブベース／固いキックとクラップ／
  細かいハット／ライザーとインパクト。
  **コードとベースとチョップは1本のサイドチェイン母線を通り、キックのたびに 0.13 まで潰れて戻る。**
- **ボーカルチョップはスクラッチ音源と同じ声。** 合成した母音を `AudioBufferSource` で
  ピッチを上げて短く切って鳴らしている。だから曲と擦っている音の出どころが一致する。
- **スクラッチ音**：`OfflineAudioContext` で鋸波＋ノイズを3〜4本のバンドパス（フォルマント）に
  通して母音を合成 → `AudioWorklet` が位置を線形補間で読む。ジョグの速さがそのまま音程になり、
  止めれば止まり、逆に回せば逆再生される。
- **譜面は曲と同じ小節予約から生えている**ので、曲と譜面がズレる余地が構造的に無い。

## 技術の要求（GAME MODE）

多少タイミングがずれていても、ジョグ方向・移動量・フェーダー開閉・順序が合っていれば成功。
ただし**本物の動きから外れているときは、必ず理由を日本語で出す**。

| | 判定 |
|---|---|
| PERFECT | ±70ms |
| GOOD | ±155ms |
| MISS | それ以上 |
| 逆方向 | WRONG「逆。手前に引く」 |
| フェーダーを閉じたまま | WRONG「フェーダーが閉じてる」 |
| CHIRP でカットしない | **GOOD 止まり**「切れてない」 |
| **BABY を同じ方向で続けた** | **GOOD 止まり「交互に！」** |

**BABY の交互ルールがこのゲームの芯。** ベイビースクラッチは前と後ろの往復であって、
同じ方向に押し続けるのはベイビースクラッチではない。だから同方向の連打は GOOD で止まる。
ただしコンボは切らないしライフも減らない。**罰ではなく、教える側に倒してある。**

## 実測したこと（Chrome / localhost）

- 通し1曲：**224ノーツ全部を自動プレイで判定 → PERFECT 224 / MISS 0 / S+ 100%**（約95秒）
- 判定幅：+110ms → GOOD ／ +200ms → MISS
- BABY 同方向の連打 → 1発目だけ PERFECT、以降14回 GOOD「交互に！」。**ライフは減らない**
- 逆方向 → WRONG「逆。手前に引く」→ ライフ0 → リザルト
- CHIRP でカットしない → GOOD「切れてない」。TRAINING の BPM は 100→108 へ上昇
- 音：静止時 0 ／ 前回し 0.824 ／ 後ろ回し 0.833 ／ フェーダーカット時 0（波形解析）
- 曲：ドロップ中の master RMS 最大 0.276、キックごとに落ちて戻る（サイドチェインが効いている）
- コンソールエラー 0

## 実測していないこと

- 🔴 **DDJ-FLX4 実機。** 手元に機材が無いので一度も繋いでいない。
  既定のMIDI割り当て（`ch1 CC34` / `ch2 CC34` / `ch7 CC31`）は
  **Pioneer DDJ 系の一般的な値からの推定**で、FLX4で検証した値ではない。
  **合わなければ MIDI 画面で覚え直せば動く**（`localStorage` に保存）。これが本命の経路。
- `T.STROKE_TICKS`（1ストロークと認める回転量）と `T.JOG_SAMPLES`（ジョグの重さ）は
  実機のジョグ分解能を見ていないので当て推量。**最初に触るのはこの2つ。**
- 音量バランス（`T.VOL_MUSIC` / `T.VOL_SCRATCH`）をヘッドホンで聴いていない。
- Google Fonts（Anton / Zen Maru Gothic）を読みに行く。オフラインだと
  Impact と Yu Gothic UI へ落ちる。**落ちても崩れないスタックにはしてある。**
